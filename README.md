# 狗狗｜陪伴的每一天

這是網站版的靜態檔案，首頁為 `index.html`，可透過 GitHub Pages 發布。寵物資料存在每位使用者自己的瀏覽器本機儲存空間，不會自動同步。

## GitHub Pages

Repository Settings → Pages → Build and deployment 選擇 **Deploy from a branch**，Branch 選 `main`，資料夾選 `/(root)`。完成後網站網址為 `https://yuchencheng86.github.io/DOGGG/`。

## 更新網站

將 Android Studio 專案 `app/src/main/assets/www/` 內修改後的網頁檔案複製至 repository 根目錄，再提交變更即可。
